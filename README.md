# ServerHostingTemplate ⚡️

---

## 🎁 Dependencies

- [Bun](https://bun.sh)
- [Node.js](https://nodejs.org)
- [Git](https://git-scm.com)

---

## 💾 Installation

1. **Clone the repositories:**
   ```bash
   git clone https://github.com/LydonDev/Server-Hosting-Template.git
   ```
2. **Install dependencies:**
   ```bash
   cd Server-Hosting-Template
   bun install
   ```
3. **ServerHostingTemplate**
   ```bash
   bun run dev
   ```
